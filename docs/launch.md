# Retired Launch commands

LaunchPool, HODLer Airdrop and CandyDrop commands were removed in v0.9.0. `gate-cli cex launch` is unavailable and has no replacement CLI command. Other `cex earn` commands remain available.

Use the Gate website to manage any remaining participation. See the [version history](../CHANGELOG.md#v090---2026-11-03) for the removed command list.
